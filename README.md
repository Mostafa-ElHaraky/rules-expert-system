# Expert System Rules with PyKnow/Experta

A rule-based expert system implementation course enrollment management using the Experta (PyKnow) library in Python. The system demonstrates various logical operators, conditional elements, and rule prioritization techniques.

---

## Project Overview

This project implements an expert system that simulates a university course enrollment advisor. It demonstrates the use of declarative programming and rule-based reasoning to make enrollment decisions based on student qualifications, prerequisites, course capacities, and special permissions.

### Key Features

- **Student Eligibility Checking** – GPA requirements and course completion verification
- **Prerequisite Management** – Automatic prerequisite validation
- **Capacity Management** – Seat availability tracking
- **Rule Prioritization** – Using `salience` for rule execution order
- **Multiple Logical Operators** – AND, OR, NOT, EXISTS, TEST
- **Pattern Matching** – Field constraints and variable binding
